## 一、动机：纯组合数学把墙从"存储侧杠杆"挪到"表示类型"（第一档 arithmetic）

v128/v129/v130 三条存储侧杠杆（选择/保留/覆盖）全部撞同一堵墙。设计期纯组合数学（零调参，已验证）发现了一个关于**表示类型**的事实：

1. 世界 = C(8,4) = **70 个节点**（有限、小）。
2. `couples(m,x)` 要求 m⊆x 且 popcount(m)≥W-1=3。→ **weight-2 掩码耦合 0 个节点**，在 W=4 世界里**结构上永远惰性**。而 base ops 和 local_variation **都只产 weight-2** → 库被灌满永远不能耦合的废铁。实测 v130 死亡（seed101 drift0.01）：库 20 = {w2:12, w3:1, w4:7}，**60% 惰性**，死亡那一步 0 个能耦合。
3. 一个完整静态覆盖只需 **23 个 weight-3 点 ≤ MAX_OPS=40**（贪心，已验证）→ **容量不是墙**，且完整覆盖**不需要预测**。v130 的 OC-12 绝望是关于"预测漂移"，但静态全覆盖无需预测。真正的失败是：写入器**从不构建/保持**一个覆盖设计，只挤在最近轨迹上（认知2 big-not-deep）。
4. **关键**：一个 weight-3 耦合子 = weight-4 pattern 减一个通道 = **两个 weight-2 子特征的 UNION**。agent **已经在铸 weight-2 特征**，只是**不能在点火时组合**它们（组合只在慢速 mint 时发生）。
5. **已验证上界（第一档模拟）**：点火时 union 全部"被观测确认的 weight-2 特征"，耦合 **70/70 节点**，drift {.01,.02,.05,.10} 存活 **1.00**、gamma **~0.70**（≫0.4333），**零 pattern 存储、零漂移预测**。函数由"按需组合通用特征"涌现。

**重构（v131 所测）**：墙在**知识表示类型**。现 agent = 外延联想查找表（存 {0,1}^8 的常数点，子集匹配）；面对移动目标须不停重存，而写入器慢+conc塌缩+偏产惰性 weight-2。需要 = 内涵函数计算器（存**通用可复用特征**〔少、对漂移稳定：weight-2 特征 {a,b} 对任何含 a,b 的 pattern 都有用〕，点火时**组合**成具体答案）。存通用的少数，算具体的多数。这正是腿①组合层级，也正是逻辑电路干的事（可复用门按输入组合，而非每输入存一个答案）。

> **纪律注（K-BIOLOGY/ANALOGY-NOT-PROOF）**：电路类比只是**假设来源**；正面论证是上面 1-5 的**实测组合数学**+剂量反应，不是"因为我是神经网络"。

## 二、机制与守卫

- **唯一被扫结构变量 = COMP_MODE**（点火组合范围），单调三档：
  - `OFF`：点火单个 op（conc 加权），**逐位复现 v130** → 回归对照。
  - `PAIR`：union **被 sensed 确认的**（mask⊆sensed）最高 conc 的 2 个特征。最小组合。
  - `ALL`：union **全部**已确认特征。最大组合、无选择（诚实的 0.70 规则，但从 6 随机特征冷启动**内生**达到，绝不 hand 满 28 基）。
- **已确认特征（冻结）**：活 op o 满足 (o.mask & sensed)==o.mask。union 后仍⊆sensed。**只读 ops+sensed，结构上不能看真 pattern/W**（K-HUMAN-DOOR 由代码读取范围强制）。
- **信用分配（冻结，表示层设计选择）**：组合点火 = 一次行动（一次 ACT_COST，成功一次 GAIN）。成功→每个成员 conc+=CONC_UP、fails=0、dormant=False；失败→每个成员走单 op 同样的 partial/punish/dorm/clear。**共享信用**是让通用特征"因参与获胜 union 而存活"的机制。
- **全部 v1.17 常数冻结**；冷启动 6 随机 weight-2（非满基）；全额交租 THRESH=0.0；drift [0,0.01,0.02]；40 seeds；world SMALL(8ch) W=4。

## 四、判决 = H-COMP-PARTIAL

**成立的部分（第一档 measured）**：
- 组合是**第一个**在全额交租·漂移0.01下把存活推过 0 的**诚实**机制（PAIR/ALL 各 1/40 活到 4000，OFF 0/40）。
- gamma 0.558→0.730（**过地板 0.4333**），ER_paid +0.361→+0.882，中位寿命**三倍**（450→1348）。
- 组合确实点火（comp_fire_frac 0.82），早期库确实 spanning（PAIR block0 span 6.2 ≥ SPAN_CUT=6）。
- **腿①方向被确认**：表示类型升级（存通用特征+点火组合）是一个**真实杠杆**，不是死路。

**不成立的部分（第一档 measured）**：
- **P-BEAT-ORACLE FAIL**：组合存活 0.025 **< oracle 0.075**。没有超过点存储天花板。
- **残留瓶颈 = 库维持（feature 抗侵蚀）**：每个臂（含 oracle）的 spanning 基都**单调塌缩**（span→0.1，|L|→0）。组合**减缓**侵蚀（PAIR 撑 8 block vs OFF 2 block）但**止不住**。
- **ALL 比 PAIR 死得快**（733 vs 1348）：广域共享失败信用 = 一次失败惩罚**全部**已确认特征 → 关联式 mass conc 暴跌 → mass 清除。**这是 v1.16 大规模删除的回声**。→ **组合必须是小信用组（局部 PAIR），不能 ALL**。

**为什么 hand满基上界（0.70/1.00）没兑现**：上界把 28 个特征**写死、永不死**；内生 agent 的特征会被 conc 衰减+clear+dorm+forget+MAX_OPS 竞争**侵蚀**。差距**全部**在侵蚀/维持动力学，不在表示类型本身。

## 五、诚实订正（flag-don't-delete）

我在向 Jayson 报告 v130 后提出"**墙就是表示类型**"。v131 证明这个说法**过强**：
- 表示类型**是**一堵墙（组合把 gamma 抬过地板、寿命三倍、首次存活>0）——这部分成立。
- 但它背后还有**第二堵墙**：库无法在漂移下**维持** spanning 特征基。hand满基上界仪器**掩盖**了这第二堵墙（因为它写死了不侵蚀的特征）。
- 订正后的图景：**腿① = 组合层级 + 通用模块**。v131 建了**组合（层级）**，但**模块仍被当作具体答案**逐次点火惩罚/清除——它们没被当作"跨多个 pattern 可复用的通用件"来保留。这正是 leg① 里我还没建的那一半。

## 六、下一步瓶颈（v132 候选，第二档登记）

**feature 维持 = 保留×组合的交互**：
- v129 已证"保留/缓刑"**单独**失败——但那是**在没有组合的世界里**。保留的通用特征当时**没有东西可组合**，所以留着也没用。
- v131 有了组合，保留的通用特征**现在有贡献**了。→ **保留×组合可能才是那个组合**（非显然、可证伪，且尊重 v129 的证伪历史：保留是在**缺组合**时被证伪的）。
- 具体 v132 假设：让通用 weight-2 特征在点火失败时**休眠但保留**（不 clear），因为一个通用模块参与多个 union，一次坏 union 就清除它 = 销毁可复用材料（违反 P2-B1/C2.3 的"单次操作不得静默删除候选枢机"）。**局部（PAIR）组合 + 特征保留** 应同时压住侵蚀与 mass 清除。
- 靶子：hand满基上界 gamma 0.70 / 存活 1.00；须超过 oracle 0.075 才算 dissolve 墙（H-COMP-LIFTS-WALL）。
