## 1. 被扫的唯一结构变量：确认入口 CONF_MODE × 窗口 K

维护 agent 自己的观测窗口（最近 K 次 `sensed`，**新状态**，不动任何常数），持续集 `P` = 窗口内**严格多数**（> len/2）点亮过的通道。`P` **只由 sensed 历史算出**（K-HUMAN-DOOR：从不读真 pattern，从不读 W）。

| 入口 | 确认判据 | 含义 |
|---|---|---|
| **INST** | `mask ⊆ sensed_t` | v131/v132 原样：单次瞬时含噪读数 |
| **PERS** | `mask ⊆ P` | 时间池化入口（K 次独立噪声抽样的多数） |
| **BOTH** | `mask ⊆ sensed_t` **且** `mask ⊆ P` | 两套离散化的**一致**（保守共识；重合=真折痕，分歧处=测量） |

下游**完全是 v131 PAIR 原样**：确认特征的 union（PAIR = conc 最高的 2 个；不足 2 个则回落 v130 单 op conc 加权路径）、共享信用给点火成员、保留档固定 R0 CLEAR（v132 已证伪 RETAIN/SUPPRESS）。
K=1 时多数=该次读数 ⇒ **PERS(K=1) 必须与 INST 逐位相同**（回归锚 C）。

## 8. 机制归因（为什么降噪能救存活，而不只是让 gamma 好看）

1. **因果链**：瞬时读数每次有 30% 概率被换掉一个通道（I1=0.6 位）。用被污染的读数去确认特征 ⇒ union 里会混进**没亮**的通道 ⇒ `couples` 要求 `mask ⊆ 真 pattern` 失败 ⇒ **一次伪失败**。伪失败走 v131 的惩罚路径（conc −0.6 + 部分信用、fails+1，连错 3 次休眠，conc<0.3 且 fails≥1 即清除）⇒ **好特征被伪失败杀掉** ⇒ 库塌 ⇒ 覆盖失败 ⇒ 更多失败 ⇒ 雪崩（v128 测到的死因）。
2. **降噪切断的正是这条链的第一环**：I2=0.07 ⇒ 伪失败率大幅下降 ⇒ 惩罚不再误杀 ⇒ 库不再塌（|L| 稳定 20–22，span 平台 4.0）⇒ 组合有成员可 union（点火率 0.82→0.90）⇒ gamma 0.730→0.869、ER +0.882→+1.309 ⇒ 预算不再失血 ⇒ 存活 0.025→0.500。
3. **残留瓶颈换了位置（第一档实测）**：失败结构从"各半"变成**覆盖主导**——covF 0.53→**0.85**、selF 0.47→**0.15**。也就是说：现在失败几乎全是"库里根本没有能耦合当前 pattern 的算子"，而不是"有却没选中/确认错"。这与 v130 的 OC-12（均匀漂移无内生信号可优先排序）**并存但不冲突**：覆盖仍然不完整（span 4.0/8，不是 6+），只是**不完整已经不再致命**。
4. **为什么 ORACLE 在 drift 0.02 反而全死**：ORACLE 的优势是**选择**（在 triggered 里挑能耦合真 pattern 的），而选择从来不是墙（v130 已证）。ORACLE 的库同样在塌（|L| 26→0、span 5.3→0），它的失败也几乎全是覆盖失败（covF 0.88–0.93）。⇒ **v130 记下的"oracle 天花板 0.075"不是诚实 agent 的上界，它是"与 agent 共用同一个含噪入口的完美选择器"的上界。** 这是账本需要订正的一条（见 §10）。

## 9. 诚实的限制（不是包装，是下一轮的靶子）

1. **窗口是免费的（最重要的自我批评）**：K 次读数的存储在预算里**不收费**。这与库本身不收费是一致的（模型从来不按存储收租，只有 MAX_OPS 上限），所以它不是新补贴；但**v124/v125 的教训是"用不收租买来的存活不算自养"**。⇒ 必须做 **v135 候选：给存储定价**（按持有的 op 数/窗口长度每步扣预算），再看"组合 + 池化入口"是否仍活。若定价后死，本轮的 0.500 就是**仪器买来的**，不是能力。
2. **入口只升级了一处**：本轮只把**组合确认**换成 P/BOTH；`triggered`（点火触发，1 位重叠即用原始 sensed）与**铸造**（PREDGUS 的 `score(mask, sensed)` 仍用原始读数）都还是含噪入口。⇒ 还有两个入口位点可升级，天然的剂量-反应（v135 候选）。
3. **K 非单调**：K=9 因漂移滞后回落 ⇒ 窗口长度与漂移速率之间存在**共振/权衡**，不是"越长越好"。这条与 v1.13 的 F2（中漂移脆弱共振）形态相似，值得单独立项。
4. **主判 K=5 恰好最优**：见 §5 的标注。
5. **BOTH 与 PERS 打平但性质不同**：交集入口库质量更好（span 更高、covF 更低）而极端漂移更脆。两者取舍未定，**不**在本轮下结论。
6. **世界很小**：8 通道 W=4、C(8,4)=70 节点。池化降噪在大世界（OPEN=64 通道）是否同样有效**未测**（本轮只跑 SMALL，与 v131/v132 同口径以便回归）。
