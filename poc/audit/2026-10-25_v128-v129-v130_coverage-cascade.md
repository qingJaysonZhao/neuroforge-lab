## 一、v128 付费窗口探针（补档）

**动机**：此前所有数字都是全程均值，被 200 步启动免租期灌水。v126 已暴露矛盾——全程成功率 0.60~0.64（高于盈亏平衡 0.433）却存活 0.00。v128 只测 t≥BASE_GRACE=200 的"付费段"，并按 500 步分块报告成功率曲线，让后程崩溃不再被平均掉。

**结论**：
- PREDGUS 在漂移 0.01 付费段 gamma=0.557（**高于** 0.4333 绝对地板），ER_paid=+0.342（**为正**），但存活=0.00。均值经济学通过，个体照样死。
- trace 显示机制：预算长时间顶在上限 60、成功率升到 0.74 维持数百步，然后在 ~42 步内死掉。25 步 × 1.3 = 32.5，即 **~25 次连续零成功行动**。这是**级联（方差/尾部事件）**，不是均值亏损。
- ORACLE（完美选择+定向反应式生成）也死：漂移 0.01 存活 0.35、漂移 0.02 存活 0.00。**证明选择不是那道墙。**

**反方/边界**：0.4333 是"任意行动率下自养的必要条件"（因 q≤1），不是"每步都行动时的盈亏平衡"。付费段测量口径正确。

**置信度**：高（第一档，trace 亲验）。

## 二、v129 缓刑探针（补档）

**动机**：诊断出"新结构第一次失败就被清库"——conc=CONC_INIT=0.6，一次失败后 conc=0.5×overlap，清库线 CONC_MIN=0.3，故 overlap<0.6 的新结构**首败即删**；"连续失败 3 次才休眠"的规则永远触发不到（第一次就没了）。

**机制**：把"失败一次"与"确认无用"分开。清库保留，但先给第二次机会（CLEAR_N 阶梯 {1,2,3,5}，1=逐位复现当前行为=基线对照）。新增 rescued / cleared 计数，以区分"零结果"与"机制根本没跑"。

**结论**：缓刑**确实触发**（rescued>0），但存活**持平到下降**。→ "保留/删除规则是杠杆"这一假设**第三次被证伪**（前两次：v1.17 H-NO-RESCUE、v1.17x cap）。

**置信度**：高（第一档，阶梯含精确基线对照）。

## 三、v130 覆盖率-多样性攻击（本轮正式实验）

### 3.1 假设与被测变量
- 唯一被扫结构变量：DIVERSITY_P {0.0（对照=逐位复现 PREDGUS）、0.5、1.0}。
- 机制 CDM（coverage-directed mint）：内生，只读 ops 掩码 + sensed，**绝不读真 pattern、绝不读 W**（K-HUMAN-DOOR）。当 diversity_p 触发时，把生成导向"全局覆盖不足的通道"，试图提前铺满漂移邻域。
- 主假设 H-COVERAGE-DIVERSITY：多样性铺满漂移邻域 → 空窗变短 → 级联被压下去 → 存活 >0。

### 3.2 判决数据（漂移 0.01，全额交租，W=4，40 seeds）

### 3.3 判决 = H-NO-COVERAGE-RESCUE
- 所有 PREDGUS 多样性档位存活 = 0.00。
- **剂量-反应反向**：gamma 随 divP 单调**下降**（0.558→0.481→0.440），ER_paid 从 +0.361 掉到 −0.016。多样性越高越差。
- 机制**确实触发**但**导向错误**：D2 去重率上升（0.534→0.560，库更多样了），但 D3 邻域覆盖**下降**（0.278→0.177），covF（覆盖型失败占比）**上升**（0.53→0.71）。CDM 把生成引向"全局覆盖不足"的通道，而那些通道**不是漂移会点亮的通道**。

### 3.4 根因 = OC-12 信息学限制（第一档）
提前覆盖漂移邻域，需要知道"漂移会激活哪个当前不亮的通道"。但漂移是在不亮通道里**均匀随机**挑一个（`rng.choice(inactive)`），**没有任何信号可供优先排序**。
- ORACLE 的高 D3（0.571）是靠**读真 pattern** 得到的（作弊），不是内生能力。
- 诚实 agent 只能朝**含噪 sensed**（SENSE_P=0.30）生成，其算子常常根本不是真子集 → 这就是观察通道限制（认知5）在覆盖率上的投影。
- 因此"内生提前覆盖不可观测的均匀漂移目标"在信息论上不可能。CDM 的失败不是实现 bug，是 OC-12 的直接后果。

### 3.5 长期价值产出：D1 判别器
把付费段的失败行动按"库里是否存在能耦合真 pattern 的算子"拆成两类：
- **coverage_fail（covF）**：库里根本没有 → 覆盖问题。
- **selection_fail（selF）**：库里有却没选中/没触发 → 选择问题。

结果（漂移 0.01）：
- PREDGUS 对照：covF 0.53 / selF 0.47（98 失败步/run）——**覆盖与选择各占一半**。
- ORACLE：covF 0.93 / selF 0.07（完美选择后，剩下的失败几乎全是覆盖）——**即便如此仍死（存活 0.075）**。

意义：这是第一件能把"覆盖 vs 选择"定量分开的仪器。它同时说明：选择腿最多只能修复到 ORACLE 天花板（0.075~0.35，本身不及格），覆盖腿受 OC-12 内生信息限制。**两条腿单独都不足以在冻结常数+当前世界下达到稳健存活。**

### 3.6 回归守卫（PASS）
divP=0.0 逐位复现 v129 的付费段率：gamma 0.5581=0.5581、alpha 0.1423=0.1423、ER 0.3614=0.3614。寿命差异仅为口径（v130 报**中位**443 按 P0-2 纪律；v129 报**均值**598），动力学一致。

## 四、跨 v128/v129/v130 的收敛结论

1. **死因是级联不是均值**：付费段 gamma 高于地板、ER 为正，仍全死；trace 显示 ~25 次连续零成功行动在 ~46 步内耗尽 60 预算。
2. **选择不是那道墙**：ORACLE 完美选择仍死（0.075~0.35）。
3. **保留/删除不是杠杆**：v1.17、v1.17x、v129 三次独立证伪。
4. **内生覆盖率受 OC-12 限制**：均匀漂移无可优先信号，诚实 agent 无法提前铺满邻域。
5. **当前形态的墙可能是结构性的**：在漂移 0.01 全额交租 W=4 8通道 MAX_OPS=40 下，没有诚实机制达到稳健存活；oracle 天花板 0.075~0.35。

**置信度**：结论 1-4 高（第一档，亲验 trace + 阶梯对照 + 判别器）；结论 5 中（是"在冻结常数+当前世界内没找到机制"，不等于"框架被证明失败"——见账本纪律）。
