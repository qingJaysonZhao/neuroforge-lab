**TUF-E — Summary v2.0**

**The anomaly**
Myoelectric prosthetic hands — worn by amputees — work in production today: a 60-year-old masters a 19-DoF hand in half a day. Dexterous robot hands carrying the world's best models struggle: sim-to-real collapses, 1 s decision latency, a material change kills the policy. Same task class, opposite outcome. The missing variable is not model size. It is **architecture**.

**The principle (our falsifiable conjecture)**
Any intelligence that must act through a low-bandwidth, lossy channel — nerves, radio, tendon, bus — converges on the same solution: a compression architecture. Skills crystallize into cheap codes; only novelty pays full deliberation cost. Formally: viable agents solve a channel-cost optimization; the three-layer reflex/skill/deliberation stack is its optimal solution class, not a biological accident.

**Preliminary evidence (reproducible)**
- Three independent civilizations converged on divisor-optimal cyclic codes for timekeeping (base 10/12/20/60 all sit at local optima of the same cost function — computed, script available).
- The Yijing's 64 hexagrams close under flip/invert to a clean 12-element group — algebraic structure, not mysticism.
- **The derivation is DIY**: any competent engineer can reproduce the architecture derivation from the principle alone with the prompt pack below, on their own LLM subscription, in one afternoon. We do not ask to be believed. We ask to be run.

**What TUF-E is**
An open framework (github.com/neuroforge-lab/TUF-E) that trains agents the way viable systems learn: L0 deterministic reflexes (1 ms) / L1 compiled skill library (10–100 ms) / L2 deliberation (0.1–1 s), with a dual valve — verified success crystallizes, verified obsolescence dissolves. Reward hacking is impossible by design: no reward exists.

**Engineering direction**
A self-checking instruction protocol for dexterous manipulation: layered command space with algebraic checksums (cross-layer consistency checked at wire speed), validation matrix per release, corruption-injection tests. Hardware-agnostic: any hand that accepts the schema gains the stack.
